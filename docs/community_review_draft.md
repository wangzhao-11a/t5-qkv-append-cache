# T5 QKV 拆分与缓存追加算子：社区设计评审草稿

状态：本地草稿，未提交社区，尚未满足全部性能门槛。

单 token 解码时，融合输入按全部 Q、全部 K、全部 V 排列。本实现输出独立连续 Q，并向两份历史缓存追加当前 K/V。FP16/BF16 共用 uint16 原样搬运，不执行浮点运算；支持 L=0、奇数维度、原始 NaN 位模式和连续存储偏移视图。

接口包含正式 ACLNN 两阶段 API、独立 C++ 样例、PyTorch `run`、Kernel launch `run_direct` 以及只保存元数据的 `prepare`。详细地址推导、分核、128 KiB 双缓冲、显式 workspace=0、stream 顺序和生命周期策略见 `docs/design.md`。
